Jede Sitzung hat oben eine Schrittleiste: **Vorbereiten → Aufnehmen → Abschrift prüfen → Notiz → Abschließen**. Die Vorbereitung ist freiwillig.

## Sitzung aufnehmen oder diktieren

- **Sitzung aufnehmen** zeichnet das Gespräch auf. Dafür braucht es die Einwilligung der Patientin bzw. des Patienten. Sie erfassen sie auf der Patientenseite unter „Einwilligung Tonaufnahme“; dort drucken Sie auch das Formular.
- **Zusammenfassung diktieren** nimmt nur Ihre eigene Stimme auf, zum Beispiel direkt nach der Sitzung. Dafür ist keine Einwilligung nötig.
- Wählen Sie das richtige **Mikrofon**. Der Pegel zeigt, ob Ton ankommt.
- Mit **Beenden** stoppen Sie. Während einer Aufnahme zeigt die obere Leiste auf jeder Seite einen roten Hinweis, der zur Sitzung zurückführt.

Die Aufnahme wird in Teilen verschlüsselt gespeichert. Stürzt der Computer ab, bleiben die bis dahin gespeicherten Teile erhalten. Wird der Speicherplatz knapp, stoppt thera die Aufnahme rechtzeitig.

## Transkription

Nach dem Beenden startet die Transkription von selbst, wenn der [Autopilot](hilfe:autopilot) an ist. Wo transkribiert wird, legen Sie unter [Einstellungen](/settings) → Transkription fest:

- **Lokal**: auf diesem Computer, nichts verlässt das Gerät. Das Sprachmodell laden Sie einmal in den Einstellungen herunter.
- **Cloud**: schneller, aber die Tonaufnahme verlässt den Computer. Für Sitzungsaufnahmen mit der Stimme der Patientin bzw. des Patienten geht das nur mit einer eigenen Einwilligung zur Cloud-Transkription.

Über das Menü **⋯** neben „Transkribieren“ wählen Sie für eine einzelne Aufnahme den anderen Weg.

## Sprecher

Bei Sitzungsaufnahmen trennt thera die Sprecher auf diesem Computer. Ihre Stimme erkennt thera an Ihren Diktaten oder wenn Sie einmal „… bin ich“ wählen. Sind mehr als zwei Personen im Raum, stellen Sie „Personen im Gespräch“ ein und wählen **Neu trennen**. Einzelne Abschnitte ordnen Sie per Klick auf den Sprecher neu zu.

## Abschrift prüfen

Korrigieren Sie Verhörer direkt in der Zeile. Ein Klick auf eine Zeitmarke spielt die Stelle ab. **Abschrift bestätigen** löscht danach das Audio endgültig; der Text bleibt.
