Ihre Daten liegen nur auf diesem Computer. Ohne Sicherung gehen sie bei einem Defekt verloren.

## Notfall-Kit

Beim ersten Start zeigt Theralo einmalig den **Notfall-Schlüssel**. Speichern Sie das Notfall-Kit als PDF, drucken Sie es aus und löschen Sie die Datei danach. Bewahren Sie den Ausdruck sicher auf, nicht auf diesem Computer.

Der Notfall-Schlüssel öffnet Ihre Daten, wenn der Schlüsselbund von Windows verloren geht, und er gehört zu jeder Datensicherung. Ist der Ausdruck verloren, erstellen Sie unter [Einstellungen → Sicherheit](/settings/sicherheit) einen neuen. Der alte wird damit ungültig.

## Datensicherung

1. Unter [Einstellungen → Datensicherung](/settings/sicherung) wählen Sie einen Ordner außerhalb dieses Computers, etwa einen USB-Stick.
2. **Jetzt sichern** schreibt eine verschlüsselte Datei (.therabak) mit allen Daten und Aufnahmen und prüft sie danach.
3. Theralo erinnert Sie, wenn die letzte Sicherung älter ist als eingestellt.

## Wiederherstellen

- **Auf einem neuen Computer**: Beim ersten Start wählen Sie Ihre Datensicherung und geben den Notfall-Schlüssel ein.
- **Auf diesem Computer**: Wiederherstellen ersetzt die aktuellen Daten durch den Stand der Sicherung. Die bisherigen Daten werden nicht gelöscht, sondern in einen Ordner im Datenverzeichnis verschoben.
