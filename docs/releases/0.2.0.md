Neu in Theralo 0.2.0

- Updates direkt in der App: Theralo meldet neue Versionen beim Start und aktualisiert sich mit einem Klick. Ihre Daten bleiben dabei erhalten; vor jeder Änderung an der Datenbank wird eine Kopie angelegt.
- Papierkorb: Gelöschte Sitzungen mit unterschriebener Notiz und unterschriebene Berichte lassen sich 30 Tage lang wiederherstellen (Einstellungen → Papierkorb).
- Demo-Praxis: Auf Wunsch probieren Sie die Beispieldaten mit Ihrer eigenen KI-Einstellung aus.
